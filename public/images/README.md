# Images Directory

Place your wedding invitation images in this directory:

- `envelope-texture.jpg` - Subtle paper/envelope texture for opening screen
- `linen-texture.jpg` - Linen pattern texture for envelope surface
- `wedding-venue.jpg` - Real venue/landscape photo for hero background
- `wedding-bg.jpg` - Alternative background image for invitations

Recommended image specifications:
- Format: JPG or PNG
- Size: 1920x1080 or higher for best quality
- File size: Keep under 500KB for optimal loading
- Style: Warm, muted tones (sage green, cream, blush) to match elegant wedding aesthetic

Note: These files should be subtle and elegant - avoid overly saturated or busy patterns.
