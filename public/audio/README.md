# Audio Files

Place your audio files in this directory:

- `opening-chime.mp3` - Short chime sound for envelope opening animation
- `music.mp3` - Background music for the invitation

Note: These files should be relatively small for optimal loading. Recommended formats:
- MP3 for maximum compatibility
- Bitrate: 128-192 kbps
- Duration: 
  - opening-chime.mp3: 2-3 seconds
  - music.mp3: 30-60 seconds (looped)
