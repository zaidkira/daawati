# Dawati - دعوات زفاف رقمية فاخرة

Digital wedding invitations platform built with React and Vite, featuring elegant Arabic RTL design and bilingual support (Arabic/French).

## Features

- **Hero Section**: Animated showcase with phone mockup and CTAs
- **Testimonials Carousel**: Auto-scrolling customer reviews
- **Pricing Section**: Three-tier pricing with clear feature comparison
- **Template Gallery**: 6 wedding invitation templates with view modes
- **Comparison Section**: Digital vs paper invitation comparison
- **Features Section**: RSVP tracking dashboard preview
- **Bilingual Support**: Arabic/French language switching
- **Customer Testimonials**: Grid of customer reviews
- **Order Form**: Package and template selection with form validation
- **FAQ Accordion**: Expandable frequently asked questions
- **Contact Section**: WhatsApp and email contact options
- **Footer**: Navigation links and branding

## Tech Stack

- **React 18.3.1**: Modern React with hooks
- **Vite 4.3.9**: Fast build tool and dev server
- **Lucide React**: Icon library
- **CSS Variables**: Design system from UXMagic
- **RTL Support**: Right-to-left layout for Arabic
- **Responsive Design**: Mobile-first approach

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Development

The development server runs on `http://localhost:3000` by default.
